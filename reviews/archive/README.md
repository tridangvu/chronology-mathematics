# Archived review sheets (pre–v1.1)

Sheets stored here were written under an **older** quality reference (notably **v1.0**), where:

- C4 covered « Immediate payoff » / gain immédiat;
- C5 covered « Modern viewpoint » / justification moderne complète as a separate mandatory locus of rigor.

They are kept for **historical traceability only**.

**They are not validations under référentiel v1.1.** A publication decision for the current site requires a new sheet under [`docs/quality-validation-sheet.md`](../../docs/quality-validation-sheet.md) aligned with [`docs/quality-reference.md`](../../docs/quality-reference.md) (v1.1), filed in the parent [`reviews/`](../) directory as `<article-id>--<YYYY-MM-DD>.md`.

When migrating an old sheet into this archive, add a one-line note at the top of the file, for example:

> Archived — criteria predate editorial structure v1.1; not a v1.1 validation.
